# 구독 다이어트

매달 빠져나가는 구독을 영수증 한 장에 모아 보고, 뺄 수 있는 걸 찾아 주는 웹 도구입니다.

👉 https://2juwon.github.io/sub-diet/

## 할 수 있는 것
- 한국 주요 구독 서비스 31개, 요금제별 가격이 들어 있어요(가격 조사일 2026.10.20, 서비스마다 가격 자료 날짜 표시).
- 목록에서 고르기 / 카드 결제 문자 붙여넣기(금액·서비스·결제일 인식) / 직접 입력
- 월·연 합계, 종류별 막대, 겹치는 구독(예: 네이버플러스+넷플릭스, 유튜브 프리미엄+음악 앱), 곧 끝나는 무료 체험, 3일 안 결제 예정
- 결제일·체험 종료 하루 전을 구글 캘린더 일정으로 추가
- 영수증 이미지(PNG) 저장, 글로 복사

## 알아 둘 것
- 통신사 결합, 카드 할인, 첫 달 할인, 예전 가격 유지는 반영하지 않았어요. 내 결제 금액으로 고쳐 쓰세요.
- 입력한 구독은 이 브라우저(localStorage)에만 저장되고 어디로도 보내지 않아요.

## 가격 고치기
`index.html` 안의 서비스 표 `S`(요금제·금액), 자료 날짜 표 `D`, 조사일 `ASOF`·`ASOF_DOT`·`ASOF_YM`을 바꾸면 됩니다.
